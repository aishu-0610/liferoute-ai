# Updated Replit Prompt for LifeRoute AI

Modify the existing **LifeRoute AI** project.

Currently, the app works only for Madurai. Update it so that it works for **any selected/entered city** in the MVP.

The app should become a **multi-city centralized emergency hospital availability dashboard**.

Users should be able to enter or select a city, and the dashboard should show hospitals, filters, recommendations, and emergency contacts based on that city.

---

## Main Change Required

Instead of hardcoding the app only for Madurai:

* Add a **city selector/search input**
* Load hospital data based on the selected city
* Show emergency contacts based on the selected city/state
* Update dashboard title based on the selected city
* Make AI recommendation city-aware
* Make filters city-aware
* Make hospital update panel city-aware

Example:

If user selects **Madurai**, show Madurai hospitals and Tamil Nadu emergency contacts.

If user selects **Chennai**, show Chennai hospitals and Tamil Nadu emergency contacts.

If user selects **Bengaluru**, show Bengaluru hospitals and Karnataka emergency contacts.

If user selects **Mumbai**, show Mumbai hospitals and Maharashtra emergency contacts.

If user selects **Delhi**, show Delhi hospitals and Delhi emergency contacts.

---

## Important Concept

The user should first choose or type a city.

Then the website should show:

> Emergency hospital availability for that selected city.

Do not show only Madurai by default unless no city is selected.

## AI Recommendation Changes

The AI recommendation should be based only on hospitals in the selected city.

It should consider:

* Selected city
* Selected area
* Selected facility
* Emergency level
* Status
* Beds available
* ICU beds
* Ventilators

Example recommendation:

> “No suitable hospital found in the selected city. Try another facility, area, or contact the emergency helpline shown above.”
